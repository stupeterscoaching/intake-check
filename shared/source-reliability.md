# Source reliability

A fact is only as good as the document it came from. Two things to check before
anything is asserted.

## Is the document authoritative?

| Signal | Treatment |
|---|---|
| Signed and dated by both parties | Authoritative. |
| Marked draft, unsigned, or with a blank signature block | **Not authoritative.** May be reported as present; never used as the governing term. |
| Names a different person or a different employer | **Does not belong to this file.** Report as misfiled. Never used as evidence. |
| Superseded by a later signed version | The later one governs. Report both if they differ. |

## Is the source legible?

Applies equally to a poor scan and a poor call transcription. Same problem, same
rule.

- If a value is unclear, **say it is unclear.** Do not read through to a guess.
- Quote what the source actually shows, including the damage, where it matters.
- A date that reads `1 2 Augus t 2021` is reported as illegible, not as
  12 August.
- If a claim cannot be checked because the source is unreadable, that is a
  finding. Say so.

## Absence

Nothing on file is **not** disagreement. If a claim cannot be checked because no
document covers it, report it as unverifiable and name what is missing. Never
treat a missing document as evidence the client is wrong.
