# Client files

Five client intake files. **Everything here is fictional** — no real person,
employer or firm. Drafted as Ontario, Canada.

Each folder holds:

```
intake-notes.md    notes from the intake call
intake-form.md     the question set and the client's answers
docs/              contracts, pay statements, ROEs, letters, warnings
output/            created as the pipeline runs; its contents are the state
```

Real client material never goes in this repo.
